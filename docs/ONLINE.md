# Онлайн

Игра онлайн только внутри Artifact claude.ai, где страница получает возможности через `window.claude.use(...)`. Вне него (локально, GitHub Pages) работает автономно.

## Возможности
- `db` — общая база. Коллекции:
  - `market/<planet>_<good>_<b|s>` → `{p, t}`: давление цены и время записи. Запись из `PressureStore.onWrite` с задержкой (`queueMarketWrite`).
  - `pilots/<uid>` → `{name, worth, peak, day, trips, over, ts}`: рейтинг пилотов, сортировка по `peak` убыв., топ 20.
- `user` — `id()` и `can('data.write')`.

## Права, объявленные для Artifact
`pilots`: читать — все, у кого есть доступ к странице; писать — владелец. `pilots/{self}`: запись — пользователь только в свой документ. Объявление хранится при публикации и переносится вперёд; менять его нужно явно параметром `capabilities`.

## Поведение при сбоях
Нет `window.claude`, ошибка подписки или `invalid_argument` при записи — игра продолжает локально. Не добавлять код, который блокируется сетью.

## Идеи
Серверная проверка рейтинга, сезоны, общий рынок с анти-абузом, события для всех игроков.
