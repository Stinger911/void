# Графика

Файл в `art/` с именем слота (без расширения) подхватывается сборкой автоматически. Допустимы `webp`, `png`, `jpg`, `jpeg`, `svg`. Готовые промпты для GPT Images — `prompts.html`. Если файла нет, элемент не рисуется или показывается встроенная заглушка (летящий цеппелин и облака в окне перелёта).

| Слот | Где | Формат |
|---|---|---|
| `banner` | полоса над заголовком | 4:1 |
| `port-zagrata`, `port-tarnok`, `port-ahadir`, `port-velmar`, `port-eltram`, `port-seryi` | шапка порта (~21:8) и миниатюры карты (16:6) | 3:2 |
| `ship` | вкладка «Цеппель» (3:1) и спрайт в полёте (~96 px высоты) | прозрачный фон |
| `sky` | прокручиваемое небо; плитка зеркалится, швы не видны | горизонтальная полоса |
| `crew-ast1..3`, `crew-eng1..3`, `crew-gun1..3`, `crew-qm1..3` | портреты карточек, 64 px | квадрат |
| `good-coal`, `-food`, `-cloth`, `-boilers`, `-spice`, `-med`, `-arms`, `-metal`, `-blueprint`, `-relic` | иконки товаров, 28 px | квадрат, прозрачный фон |
| `ev-pirates`, `ev-storm`, `ev-salvage`, `ev-sign-bad`, `ev-sign-good`, `ev-bankrupt` | окна событий и бюллетень | ~16:7 |

Для Artifact файлы из `art/` публикуются параметром `files`. Для сборки в один файл большие картинки лучше сжимать в webp, чтобы `index.html` не раздувался.

## Лист интерфейса

`art/ui-sheet.png` (сетка 8×8) нарезает `slice-ui.py` на спрайты `art/ui-*.png`. Шахматный фон в листе «запечён» в пиксели, скрипт убирает его заливкой. Нужен Pillow (`python3 -m venv .venv && .venv/bin/pip install pillow`). Кнопки, вкладки и рамки панелей и модалок подключены в `style.css` через `border-image`, иконки датчиков через `artImg('ui-i-…')`. Стрелки цены (`ui-up`, `ui-down`) стоят в строках рынка, тумблер (`ui-tog-*`) переключает тему. Спрайты со свечением (`ui-btn-glow`, `ui-card-sel`, `ui-i-void`) сохраняют кайму от шахматки, поэтому в интерфейсе не используются.
