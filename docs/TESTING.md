# Тесты

Нужен Node и `npm install` (jsdom).

| Команда | Что проверяет |
|---|---|
| `node sim.js careful 80 80` | Баланс: осторожный бот с запасом и наймом. Аргументы: режим, число прогонов, число рейсов |
| `node sim.js reckless 80 80` | Безрассудный бот; должен разоряться почти всегда |
| `node lore-test.js` | Лорные правила: ямауда, Знаки, двухэтапный рейс, пираты по планете отправления |
| `node price-test.js` | Раздельное давление покупки и продажи, затухание |
| `node ui-test.js` | Сборка `index.html` в JSDOM с подставной `db`/`user`: слайдер, пауза перелёта, возобновление после перезагрузки, банкротство. Должна закончиться строкой `errors: []` |

Перед коммитом: `python3 build.py && node ui-test.js`. Тесты читают собранный `index.html`.
