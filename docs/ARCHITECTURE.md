# Архитектура

```
core.js (чистая логика) ──► app.js (UI, сохранение, сеть) ──► index.html (build.py)
                                 ▲
                         art/* (по именам слотов)
```
- **Состояние** игры — один объект `s` (`newGame(name)`), сериализуется в JSON. Функции ядра принимают `s` и меняют его.
- **Результат действия**: `{ok, msg, ev?}`; UI показывает `msg` через `toast`.
- **Время**: `PressureStore(now)` и `depart(..., {now})` получают часы снаружи. Для симуляций `{instant:true}` пропускает паузу перелёта.
- **Случайность**: от `s.seed`, поэтому тесты воспроизводимы.
- **Перелёт**: `depart` → `s.flight`; `completeFlight` бросает событие; `resolveFlight(s, choice)` решает пиратов; `jump` — Пустота; `arrive`/`finishFlight` — прилёт.
- **UI**: рендер-функции `renderMarket/Map/Ship/Crew/Rank`, модалки пиратов, знака, конца игры, диалог сделки со слайдером, окно перелёта (`buildFlightBox`, `tickFlight` каждые 200 мс).
- **Сборка**: `build.py` склеивает файлы, убирает защиту `module.exports`, вставляет манифест `ART`. В тексте JS не должно быть `</script`.
- **Сохранение**: `localStorage`, ключ `SAVE_KEY`; при загрузке возобновляется перелёт, ожидающие пираты и конец игры.
