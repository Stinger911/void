# Медный Горизонт

Браузерная игра-торговля в стиле Elite по мотивам цикла «Герметикон» Вадима Панова (стимпанк, цеппелины, карточный экипаж).

- Сборка: `python3 build.py` → `index.html` (один файл).
- Картинки: положить в `art/` файлы с именами слотов (см. `prompts.html`), затем пересобрать.
- Тесты: `node sim.js`, `node lore-test.js`, `node price-test.js`, `node ui-test.js` (нужен jsdom).
