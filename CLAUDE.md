# Медный Горизонт — инструкции для Claude Code

Браузерная игра-торговля в духе Elite по мотивам цикла «Герметикон» Вадима Панова. Стимпанк, цеппели, экипаж из карточек, общий рынок и рейтинг пилотов онлайн. Владелец проекта: Andrew, общение на русском. Тексты игры, комментарии в коде и ответы пишем по-русски.

## Быстрый старт
```
npm install            # только для тестов (jsdom)
python3 build.py       # core.js + app.js + style.css + body.html (+ art/) -> index.html
node sim.js careful 80 80     # баланс: режим (careful|reckless), прогонов, рейсов
node lore-test.js && node price-test.js && node ui-test.js
```
`index.html` — результат сборки, один самодостаточный файл. Его коммитим, но руками не правим: правки только в исходниках, затем `python3 build.py`.

## Карта файлов
| Файл | Что внутри |
|---|---|
| `core.js` | Чистая игровая логика без DOM: константы, товары, планеты, карточки, цены, рейсы, пираты, Знаки Пустоты, банкротство. Экспортируется через `module.exports` для тестов |
| `app.js` | Интерфейс, сохранение, онлайн (`goOnline`), окно перелёта, модалки, слоты графики (`ART`, `artImg`) |
| `style.css` | Стили, светлая и тёмная темы через токены |
| `body.html` | Каркас страницы с заглушками `@@CSS@@` и `@@JS@@` |
| `build.py` | Сборка; подставляет `const ART = {...}` из папки `art/` |
| `art/` | Картинки; имя файла без расширения = имя слота (см. `docs/ART.md`) |
| `prompts.html` | Промпты для GPT Images по всем слотам |
| `sim.js`, `lore-test.js`, `price-test.js`, `ui-test.js` | Симуляция баланса и проверки |
| `docs/` | Дизайн, архитектура, онлайн, графика, тесты, дорожная карта |

## Правила, которые нельзя ломать
1. **`core.js` остаётся чистым**: никакого DOM, `window`, `localStorage`, `Date.now()` внутри логики. Время передаётся параметром (`depart(s, dest, {now})`), случайность идёт от `s.seed`.
2. **Покупка и продажа имеют раздельное давление цены** (ключ `pkey(planet, good, 'b'|'s')`). Купил — растёт цена покупки, продал — падает цена продажи, противоположная сторона не меняется. Нельзя купить и тут же продать дороже.
3. **Лор важнее удобства.** Перелёт двухступенчатый: сначала путь по планете отправления (там пираты, шторм, добыча), затем мгновенный переход через Пустоту (Знаки Пустоты). Подробно в `docs/GAME_DESIGN.md`.
4. **Канон и выдумка разделены.** Ямауда имеют иммунитет к Знакам Пустоты и не могут быть астрологами. «Цепарь» — любой член экипажа, отдельной роли нет. Инженеры (шифбетрибсмейстеры) — только мужчины, брутальные. Всё придуманное для игры (имена карточек, длина этапов, шансы) помечать как выдумку и не выдавать за канон.
5. **Не менять баланс на глаз.** После правок экономики или рисков прогнать `sim.js`. Ориентир: осторожный бот банкротится в ~25–30% забегов, медиана ~35–45k; безрассудный — в 100%.
6. **Игра работает автономно.** Без онлайн-возможностей (`window.claude` нет) всё играется локально с сохранением в `localStorage`. Любой сетевой вызов оборачивать в try/catch и не блокировать игру.
7. **Версию сохранения** (`SAVE_KEY` в `core.js`, сейчас `paroviy-torg-v4`) повышать при несовместимых изменениях структуры состояния.
8. **Отсутствующая картинка — не ошибка.** `artImg(slot, cls, alt)` рисует `<img>` только если слот есть в `ART`; битые изображения удаляются обработчиком ошибок.
9. Тёмная и светлая темы обязательны: цвета только через токены `:root`.

## Соглашения
- Русские названия в интерфейсе; идентификаторы в коде латиницей.
- Роли: `ast` Астролог, `eng` Шифбетрибсмейстер, `gun` Канонир, `qm` Квартирмейстер. Карточки `ast1..3, eng1..3, gun1..3, qm1..3`; ямауда: `eng2, eng3, qm2, qm3`.
- Новые константы баланса выносить наверх `core.js` рядом с остальными.
- После правки: сборка, `ui-test.js` без ошибок, затем коммит. В сообщения коммитов добавлять атрибуцию, которую требует окружение.

## Где работает игра
Опубликована как приватный Artifact в claude.ai («Медный Горизонт»). Подробности про онлайн-режим и права доступа — `docs/ONLINE.md`. Обновление опубликованной версии выполняет сессия, у которой есть инструмент Artifact; из обычного Claude Code достаточно собрать `index.html` и запушить.
